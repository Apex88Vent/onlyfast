# Development previews

These static mockups were moved out of `public/` so Vite cannot copy them into
production releases. Run the local development server and open
`/qa/previews/rookie-mobile-preview.html`, `/qa/previews/rookie-ad-slot-preview.html`
or `/qa/previews/onlyfast-home-preview.html`. The React onboarding/ad preview
routes are also development-only. No preview is a release acceptance result.
